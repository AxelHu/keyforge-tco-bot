本页记录 **0.3.0** 在 **2026-11-16** 实际完成的验证。本版增加常用策略选单、历史 Elo 说明和配置阶段的注册 ID 校验，并修复未构建时的离线预检查入口。策略评分源码、卡牌知识和实际对局启动器未改动。

环境为 WSL 内的 Linux、Node.js 22.22.3、TypeScript 5.9.3、Playwright 1.59.1。验证命令限制在两个 CPU 上，以较低优先级执行；下列时间均为北京时间（UTC+8）。

### 回归覆盖

194 项公开测试包括 **14 项策略/知识、31 项运行时、149 项传输/看门狗**用例。新增的 9 项菜单回归直接验证真实 CLI、真实注册器及当前生产函数，包括：

- 常用/完整列表和详情，全部 89 项可发现，历史分数与默认策略分开表达。
- 选单快照对实际编译注册器的完整比对；原注册器继续作为真实运行时终检依据。
- 初始化的缺值、重复、冲突、非法 ID 和已有目录保护；有效的非默认策略原样写入。
- 未构建安装形态：保留真实生产依赖、不带 `src`、`dist` 或 Git；菜单与初始化可用，预检查报告缺少编译文件。
- 补入编译输出后，不带源码和 Git 的形态继续支持选单；冻结文件集合包含新元数据模块。
- 严格的数字选择与精确 ID、非 TTY、EOF、Ctrl+C，以及不落盘的拒绝路径。

首轮新增隔离夹具漏放了 Playwright 生产依赖，修正后第二轮暴露了真正的入口问题：离线 preflight 过早导入真实启动器，缺 build 时先报模块错误。现在 CLI 直接调用同一纯预检查函数，保留禁止 `--run` 的约束；真实 `seat run/create` 继续走原启动器。两轮失败回执保留，最终完整重跑才计为通过。

### 冻结运行时的实际核验

这次实际冻结了 **777 个包内/生产依赖文件，共 20,216,460 字节**，并绑定 **307 个外部执行/资源文件**。新快照没有 `src`、`docs` 或 `.git`，仍可查看策略历史说明、生成配置和执行预检查。

核验使用全新的合成账号配置、空密码模板和示例域名，没有读取现有凭据。连续对局准备成功；通过真实 `verifyCampaignRuntime()` 核对 manifest、包内依赖和外部执行文件。尚未启动的 campaign 状态正确返回 `CAMPAIGN_NOT_STARTED`，没有生成伪运行记录。

真实终端初始化另行确认：常用菜单显示五项，输入编号 3 后写入 `tactical-style-cycle-v2`，凭据模板权限为 0600，未创建对局输出或启动浏览器。

这些临时运行时和配置均已清理，保留必要回执与 manifest 摘要。验证没有启动 Chromium；[0.1.0 的真实浏览器检查](https://github.com/AxelHu/keyforge-tco-bot/blob/c3194401ef28547b4fd6c97651fd543edbe874d8/docs/validation.md)仍作为明确归属旧版的历史记录。

## 能运行到什么范围

公开仓已包含独立运行需要的策略、完整静态知识、浏览器桥接和后台工具；安装依赖、构建并配置好后，可在兼容部署上使用单席或连续对局入口，不需要原私有 KF 引擎、OpenClaw 或模型密钥。牌桌聊天是另行启用的可选功能。

| 部分 | 当前范围 |
| --- | --- |
| 操作系统 | Linux 或 WSL 内的 Linux；后台监督依赖 `/proc`、pidfd、内核文件锁和 Python。 |
| 本地 CLI、策略选择与冻结 | 有本版实际构建、回归和上述离线运行核验。 |
| 登录、大厅与选牌 | 要求目标站点兼容现有接口和控件；使用 `/login`、`/api/account/login`、`Select deck`、`Select row <serverDeckId>` 以及“新游戏”“开始”等按钮。 |
| 当前公开 TCO 无人值守流程 | **尚未完成端到端实战验收**；改 origin 或用户脚本网址匹配不代表已适配全部站点 UI。 |
| 规则与隐藏信息 | 远端服务器负责合法动作和结算；策略读取己方可见及对手公开信息，不带本地 Game。 |
| 专项策略和扩展 | Tullibint、预言、DoK 特征等需满足各自适用条件；选择 ID 不会绕过身份、知识或控制权检查。 |

`preflight` 只检查本地配置和文件，不读取密码、不验证登录成功、不认证站点界面。纯文件检查通过的空密码模板，仍须在真实运行前填入密码。

## 复现公开检查

```sh
npm ci
npm test
npm run check:package
node bin/kf-auto.mjs strategies list
```

额外的真实本地浏览器检查：

```sh
npx playwright install chromium
npm run test:browser
```

实际启动与连续对局步骤见[操作指南](operations.md)。`init`、`preflight`、菜单查询、`runtime freeze` 和 `campaign prepare` 都不会开始游戏；`seat run/create` 与 `campaign run` 是连接配置站点的运行操作。

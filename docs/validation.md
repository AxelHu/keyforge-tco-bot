## 国际站观察证明了什么

两次匿名探针分别从独占的新浏览器 profile 打开站点。第二次直接使用生产大厅观察器，记录协议事件名、公开字段形状和连接状态，不保留原始玩家、聊天或认证正文。登录表单和大厅控件来自真实页面；`Start`、`Leave`、`Leave Game`、选牌组件及待开始房间的带 ID 退出事件，还核对了当时实际部署的公开 JavaScript 资源。

观察证明了网页可访问、登录表单结构与匿名大厅通路相符。**它没有证明国际服账号登录成功、登录后的完整选牌／建房流程、真实游戏节点握手、游戏动作回执、整局完成或终局退出。** 当前没有可用于本次验收的国际服账号配置；这些步骤保留为下一阶段验收项。不能把匿名页面和本地组件通过写成国际服无人值守实战通过。

第一轮短观察只看到 WebSocket 升级探测；第二轮延长观察并明确允许同源 Socket.IO polling 握手后，得到完整大厅连接证据。没有据第一次缺少事件去放宽生产连接校验。

部署资源 URL、SHA-256、国际服配置与尚待验证的动态游戏节点地址，见[国际服适配说明](international-tco.md)。两次匿名探针都确认浏览器退出、PID 绑定消失、租约删除及临时 profile 清理。

## UI 和退出协议回归

离线套件包含 **14 项策略／知识、53 项运行时、152 项传输／看门狗**用例。新增 UI 回归检查实际生产观察器与函数：

- 精确区分 `Leave`、`Leave Game` 和 `Concede`，不使用模糊包含或任取首个匹配项。
- 中英控件同时出现并造成歧义时拒绝操作；禁用的开始按钮不能被点击。
- 待开始房间兼容原无参 `leavegame`，以及国际前端的一个精确绑定 `gameId` 参数；错房间、多余参数、缺少原生确认不能形成离房证明。
- 对手已到场、房间身份或 origin 不符、传输身份改变时，保留原保护条件与未知结果。
- 实际 Chromium 夹具使用独立写定的中英文 DOM，未从被测名称表生成控件。验证真实 create、选牌、离开与开始 helper，包括两个同名牌组时按精确服务器 ID 选择正确行。

本地浏览器 smoke 使用合成原生回执，未运行远端 React 应用的认证后流程。终局 `Leave Game` 的精确控件匹配有本地覆盖，国际服终局服务器回执仍需真实对局验收。

未入座恢复仍要求精确的受审源码。本版更新三个既有文件的版本绑定，并将新 UI 契约模块一并加入四项固定哈希；不将此绑定扩展到历史私有安装或其他未知版本。

## 英文聊天回归

覆盖站点默认语言、显式设置、相似域名反例、真实 CLI 错误码和零落盘拒绝；还覆盖从配置到 sidecar、模型提示和公开信息投影的传递。模型聊天关闭时，语言仍到达独立看门狗。

固定英文问候、长名称、模型失败回退、意外中文正文拒绝、公开中文专名保留，均有用例。它不是完整自然语言识别器。既有中文 persona 和默认行为保留；旧 checkpoint 与已标记未知送达的开场继续去重，不因语言变更重发。

生产 userscript、Node watchdog 和实际 watchdog-browser 组件夹具共同验证英文故障说明、精确本人回声、一次技术认输和跨 reload 不重复发送。开发阶段的四次窄测试分别为 37/37、38/38、51/52、52/52。第三次失败来自新夹具的同步回声早于尝试标记，随后按既有的回调失败与独立原生 pull 场景校正夹具；没有修改生产恢复保护。最终统一的 219 项测试覆盖了这些实现及后续真实 CLI 错误码修正。

没有调用付费聊天模型或向真实玩家发送消息；本节属于本地生产组件回归。

## 冻结运行时

实际冻结 **779 个包内／生产依赖文件，共 20,223,605 字节**，并绑定 **307 个外部执行／资源文件**。新快照没有 `src`、`docs` 或 `.git`，仍可查询全部 89 个策略、生成国际服配置、保留 `social.language: "en"`、执行离线预检查与准备 campaign。

通过真实 `verifyCampaignRuntime()` 核对 manifest、文件和外部执行依赖。尚未启动的 campaign 正确返回 `CAMPAIGN_NOT_STARTED`，没有伪造运行记录。全程只使用合成账号和空密码模板，没有读取现有账号凭据。

临时运行时与配置已经清理；本轮 CLI 核验不打开浏览器，前述 UI smoke 和匿名站点探针各自独立记录。

## 复现公开检查

```sh
npm ci
npm test
npm run check:package
npx playwright install chromium
npm run test:ui
```

另有通用浏览器归属与 PID 身份 smoke：`npm run test:browser`。该通用检查本轮没有另行重跑；本轮真实浏览器证据是上文的 UI smoke 和匿名探针。

实际运行要求 Linux 或 WSL 内的 Linux、Node.js 22.12–24.x、Python 3 和直接可执行的 Chromium。配置与启动步骤见[操作指南](operations.md)。`preflight` 只核对本地配置与文件，不读取密码、不认证站点，也不能替代真实登录与对局验收。

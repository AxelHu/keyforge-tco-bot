# 国际服线路比较与后续实测

本页记录 2026-11-16 的直连／代理比较及随后进行的实测。**本批已完成 3 场自然终局，3 场均完整自动通过；另有 1 场人工恢复后因适配缺口停止、技术认输并清理。** 前两场自然局及技术失败局使用 0.4.0 基线，修复后的 DT/DM 自然局使用 0.5.0；不能把三场通过都归给新版本。真人阶段的匹配流程已启动，尚无真人终局。早先 0.4.0 的另一批三场自然终局、一次完整自动通过另有[固定证据](evidence/international-2026-11-16.json)，不计作本批新结果。

## 已完成的匿名网络比较

主要 HTTP 对照共 48 次请求：主页、部署中的 3,008,504 字节 JavaScript 文件、匿名 Engine.IO polling 握手，各做 8 轮直连／代理配对，并交替顺序。每次使用独立 curl 进程，连接期限 10 秒、整个传输期限 25 秒，未自动重试。两次额外响应头检查不混入这 48 次。

| 测量项 | 直连 | 代理 |
| --- | ---: | ---: |
| 主页在期限内完成并返回 200 | 8／8 | 8／8 |
| 主页总耗时中位数 | 1.370 秒 | 1.838 秒 |
| 匿名 Engine.IO 握手在期限内完成 | 8／8 | 8／8 |
| Engine.IO 请求总耗时中位数 | 0.844 秒 | 1.460 秒 |
| 3,008,504 字节 JS 在 25 秒内完整下载 | 0／8 | 7／8 |
| JS 成功下载的耗时中位数 | 无成功样本 | 12.104 秒（7 次成功） |
| 已完成的 WebSocket 控制 ping RTT 样本 | 105 | 105 |
| 控制 ping RTT 中位数／P90 | 195／222 毫秒 | 299／398 毫秒 |

直连的控制 ping 往返较低，代理在本次大资源完整下载中表现更好。25 秒未下载完成是这个期限下的结果，不能推成更长时间也无法下载。请求已使用 `--compressed`；响应头检查确认送出了 Accept-Encoding，但两条路线的回复都未含 Content-Encoding。

WebSocket 测量分别连接大厅、node-0、node-1，每条基础连接计划维持约 180 秒。**四个匿名游戏节点连接在最初 `40` 确认后均收到 `41` 命名空间断开包**；底层 Engine.IO 仍继续心跳。大厅命名空间保持连接，这些节点测量仅证明基础传输，不证明已认证游戏命名空间持续可用。控制 ping RTT 也不是游戏命令确认延迟或策略思考时间。

代理侧在计划关闭的边界出现 3 次未完成的定时 ping 回调，它们可能尚未发到网络；没有将其计为丢包，也没有据此计算丢包率。另一次早期探针遗漏 Socket.IO 命名空间握手，约 45 秒后被服务器关闭，该不完整探针已从正式比较中排除。

HTTP 与 WebSocket 测量有重叠，工作站及网络没有独占。结果是当前网络条件下的短时样本，不能推算长期可靠性，也不能推广到其他代理或网络。匿名阶段的登录、建房、加入、聊天及游戏命令均为 0；没有修改全局代理设置。

### 基线 DT/DM 的故障与处置

`route06` 先出现短暂断连／桥接等待，guardian 随后重新 connected，但策略仍因 `transport-or-activity-stop` 暂停，`unknownSend` 为 false。该私有脚本关闭了 watchdog。第一次恢复请求因页面 URL 检查未通过而停止，没有刷新；第二次实际执行了 **一次原生页面刷新**，在同一个 host／runId 下将页面 ownerEpoch 从 1 更新为 2，随后继续推进对局，没有替换宿主。

恢复后，DM 席于 07:07:48 UTC 报告 `STRATEGY_UNSUPPORTED`，原因为 `allocation-hypnotic-command-public-quota-unreported`。这一适配缺口与先前的断连／桥接等待分别记录。该局累计 81 个状态、37 次决策、35／35 条命令确认；完整扫描 1,867 条证据／1,624 条游戏诊断，确实观察到 unsupported，不能沿用另外两局的“零故障”结论。

操作员随后从原生 UI 执行一次技术认输；双方原生视图一致，两边均为 0 把钥匙。两席各执行一次正常 Leave，并确认服务端成员关系从存在变为不存在；绑定的宿主、浏览器、registry、profile 和账号占用记录已于 07:14:41 UTC 全部释放。原始失败回执和 exit 2 保留。这证明现场资源已收回，不代表该局全程自动完成，也不产生自然局数或策略胜率。

### 0.5.0 修复版的完整自动通过

`route07` 使用源码 `9706d6b90d2f88a93f9d8d8c8e8c11a2021dc3b9` 的独立冻结运行时。DT 牌组自然 3:2 获胜，DT 席 189／189、DM 席 150／150 条命令确认，共 339／339；记录 686 个状态、342 次决策。完整扫描新增 6,416 条证据／4,358 条游戏诊断，八类历史故障标志和 pageerror 均为 0。Start 到双席终局为 409.233 秒，wrapper 报告 478.483 秒，最终 exit 0。

双方均通过原生完整状态核验并取得英文备用开场回显；各发送一次正常 Leave，服务端成员关系从存在变为不存在，宿主、浏览器、registry、profile 与账号占用均自动释放。全过程没有人工刷新、技术认输或人工清理。本次实际游戏节点为同源 `/node-0/socket.io`；其他运行曾观察到 `/node-1/socket.io`，这些地址仍是动态节点，不作为固定配置。

本局启用了生产 watchdog，但没有发生自动恢复事件，两席均保持 ownerEpoch 1。因此它证明启用 watchdog 时的正常完整生命周期，**没有证明自动故障恢复路径已在现场触发**。终局的精确宿主状态也确认 DM 席所有 allocation 计数为 0，所以 **本局没有执行新 Hypnotic Command 分支**；该分支的证据仍是此前真实故障的公开状态、实现推导和 7 项离线回归。DT 席另有一次 allocation，不能把它标成 Hypnotic Command。

全部四场私房均为自有账号内战，使用英文备用回复，没有真实模型调用或真人对手。原计划的 `route04-direct-gr-woe` 与 `route05-direct-dt-dm` 未启动，已因重复冷启动风险跳过，不计失败对局或胜局。真人阶段的运行流程已于 07:36:06 UTC 启动，尚无已完成的真人对局；有限自动批次尚未开始。本批没有新增 Elo 或真人胜率估计。

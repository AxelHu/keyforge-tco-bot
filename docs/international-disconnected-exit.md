## 0.5.1 的修复

源码 `365f06abdb81b13c47a9c1f1c48acd8e1f991eba` 新增可选配置：

```json
{
  "leaveAfterFinish": true,
  "watchdog": { "enabled": true },
  "disconnectedOpponentExit": { "enabled": true, "waitMs": 120000 }
}
```

将这些字段合并到新席位配置的顶层，再准备新的 campaign。默认 `enabled` 为 `false`；支持精确站点 `https://thecrucible.online`，等待时间范围为 120000–900000 毫秒。旧配置、旧冻结运行时和福州服原有行为不被热更新。

退出需同时满足：原生视角确认对手断线且轮到对手，本人连接正常，账号与房间绑定一致，没有待发或送达未知的命令，没有人工暂停，页面明确提供无损 `Leave Game`。原生连续观察达到等待时间后，只点击一次正常离桌；随后检查真实 outgoing `game/leavegame`，通过独立匿名名册证明从在席变成离席，再退出精确的宿主、浏览器和驱动。

两次轮询之间的短暂重连、异步名册查询期间的重连、原生 full 重同步跨序号，都会使旧的连续断线计时失效。观察器关闭或失效时不能依据旧状态继续点击。普通在线等待和本方故障仍按既有流程处理。

结果独立记为 `opponent-disconnected-departure`，占一次尝试，不增加自然胜负或策略技术失败。驱动还活着时只允许 `awaitingDriverExit`；实际 exit 0 且资源确认完成后才可继续。退出或资源状态无法确认时保留现场并停止新局。

# 0.6.2：牌区转移与再次使用机会的估值

> 0.6.2，2026-11-18（Asia/Shanghai）。已完成 32 局基线诊断、96 局开发比较和 384 局确认比较，完整离线回归 549／549。确认批次候选 192 胜 192 负。两个策略家族的确认区间均包含 50%；本轮确认了局部规则与估值缺口的修正，尚未证实稳定的整体胜率提升。
>
> [脱敏数据与逐局核验摘要](evidence/card-lifecycle-2026-11-18.json) · [发布输入记录](../PUBLICATION.json)

本轮改进围绕一个具体问题：同一张牌从手牌、弃牌堆、档案或场上移到另一区域，会怎样改变之后能够使用它的机会？回收一张当前可打出的关键行动牌、归档一张暂时无法使用的牌、弃掉一张仍能再次抽到的牌，以及清除一张牌，不能只用一个与区域和时机无关的牌面分数比较。

0.6.2 在已有公开效果估值之上增加区域转移估值，分别记录实际目的地、保留或失去的使用机会，以及整次候选动作对正常补牌的影响。规则确定性与策略效用的近似程度分开记录。以下结论限于已支持的结构化效果和公开信息。

## 1. 先观察实际决策，再确认问题

### 1.1 冻结 0.6.1 的 32 局诊断

改动前使用冻结的 0.6.1 运行时完成 32 场预先固定的诊断对局。每场双方使用同一策略家族；两个家族分别观察。32 场均自然结束，技术终止和对局上限终止均为 0。

记录器保存当前行动方收到的公开 Observation、当时全部合法候选及其评分、实际选择，以及同一行动方在命令执行后的公开观察。统计单位如下：

| 项目 | 数量 | 口径 |
| --- | ---: | --- |
| 已完成诊断对局 | 32 | 固定诊断批次，独立于后续强度对照 |
| 行动方决策快照 | 6,564 | 各类实际决策事件，包含出牌、选屋、选择目标等 |
| 合法候选记录 | 52,046 | 上述事件中的全部候选；同一张牌可在多个事件中重复出现 |
| 精确识别的非在场牌归档提示 | 25 | 由原生动作或明确的结构化 intent 确认归档操作 |
| 这些提示中的目标候选 | 415 | 目标候选记录数，不是 415 次独立归档机会 |
| Tick-Tock 可选归档提示 | 11 | 11 次均实际选择 Done |
| 操作尚未被记录器精确解析的 select | 1,829 | 保留原公开上下文，不将其自动归类为某种区域转移 |

25 个归档提示可以进一步拆开：

| 来源 | 目标提示 | 目标候选 | 观察到的行为 |
| --- | ---: | ---: | --- |
| In Here Somewhere… | 14 | 223 | 来自 7 次强制归档两张牌的完整结算；这些目标候选评分全部为 0 |
| Tick-Tock | 11 | 192 | 每个可选提示中目标候选与 Done 均为 0；11 次实际选择 Done |

这里确认的是估值覆盖和候选区分缺口：真实提示允许操作这些牌，旧消费者对非在场归档没有提供有效的目标差异。该证据无法单独确定每个提示的最优目标，也不能据此认定 11 次 Done 全部错误。

52,046 个候选涵盖所有动作种类，不能作为生命周期决策的样本量。对尚未精确解析操作的 select，也不能反推出“没有发生回收、清除或归档”。牌面包含某个操作，仅能作为覆盖线索；实际统计以当时明确的动作或 intent 为准。

诊断局中的胜负不用于标注此前某个选择的对错。32 局及其抽取出的公开场景属于已查看的开发证据，不计入之后的确认样本。

### 1.2 Witch of the Eye 的第三钥匙反例来自受控局面

另一个已证实问题来自独立构造的合法固定局面：己方已有两把钥匙，Witch of the Eye 已完成收割并打开回收提示，当前为 Untamed，当前有 7 琥珀，钥匙费用为 6，弃牌堆中有 Key Charge 与另一张普通生物牌。

旧评分在这个局面中更偏好生物牌。冻结裁判独立执行“回收 Key Charge → 正常打出 → 支付文本要求 → 铸造第三把钥匙”，确认存在合法获胜路径。回收后的正常出牌机会没有得到适当优先级，是这个受控反例所证明的缺口。

这不是 32 场自然诊断中反复出现的错误。自然诊断中确实出现过 Witch 的回收选择，但该样本没有 Key Charge 候选，也没有证实漏掉第三钥匙。文档和统计分别保留这两类证据，不把受控获胜路径写成自然局发生频率。

### 1.3 Labwork 的窗口需要按实际阶段判断

窗口隔离检查还确认了一个容易忽略的差别：Labwork 打出后打开归档选择时，当前行动阶段尚未结束。归档当前屋仍能正常打出的牌，会放弃这个回合的可用机会；归档另一屋的牌，则可能保留较多后续价值。

测试用相同的基础牌值隔离时机因素，检查模型是否仍能区分这两种情况。对应消费者测试保留较强的当前屋行动牌，优先归档暂时不能正常打出的另一屋牌。这个结论依赖具体公开局面，不构成所有 Labwork 提示的一条固定选牌规则。

## 2. 使用机会差：V(to) − V(from)

生命周期分量按同一张已知物理牌移动前后的机会差估计：

```text
生命周期分量 = 对己方有利的方向 × [V(实际目的地) − V(原区域)]
             + 整个候选动作的一次正常补牌差分
```

这里的 V 表示牌在相应区域中保留的使用机会，单位是策略内部效用分。它不表示胜率，也不是精确的长期回报。场面移除、资源变化等已有分量仍由各自消费者计算；生命周期部分补充场外可达性，避免把同一份场面价值或释放的俘获琥珀重复相加。

牌的所有者决定它未来回到谁的可用资源中；当前控制者决定已有场面价值和部分离场资源的归属；档案持有者决定由谁的档案步骤发起取回。三者分别处理。

| 区域转移 | 需要比较的机会 | 不能额外计入的收益 |
| --- | --- | --- |
| 手牌 → 档案 | 当前可打出的机会与以后可控取回的机会 | 每归档一张都固定获得一个补牌位 |
| 弃牌堆 → 档案 | 等待再循环与等待档案取回之间的差别 | 原本没有占手牌位置，不能直接当作清出手牌 |
| 弃牌堆或档案 → 手牌 | 有条件的当前出牌窗口、以后留存价值、补牌占位 | 回收到手不等于已经出牌或已经铸钥匙 |
| 手牌 → 弃牌堆 | 放弃当前持有机会，保留之后循环或原生回收的机会 | 未实际触发的 Scrap、Destroyed 或其他响应 |
| 已知牌 → 清除区 | 失去正常抽牌循环中的可达性 | 不把弃牌与清除当作同一个目的地 |
| 已知牌 → 牌库顶、牌库底或洗回 | 已知顶牌的近期抽取、到底的遍历等待、真实洗牌后的机会 | 未公开的牌库顺序或下一张牌身份 |
| 场上 → 手牌、档案、牌库、清除等已支持的直接移区 | 既有场面变化加上未来使用机会 | 重复计算场面移除、俘获琥珀归还或 Destroyed 收益 |

普通 destroy、sacrifice 和战斗致死继续使用原有破坏估值；本轮没有为这些路径统一叠加弃牌堆中的未来使用机会。

清除区的普通循环机会取 0，含义是“不能通过正常抽牌循环再取得”。这个约定不声称所有牌面机制都永远无法取回清除区的牌；未建模的特殊取回路线仍在本轮边界之外。

## 3. 基础牌值复用已有公开效果估值

本轮没有建立一份按牌名排列的“关键牌高分表”。普通质量估计优先复用已有公开效果估值器：

1. 若该牌已经有当前真实合法的 Play 候选，使用这些候选的普通效用分量。
2. 对公开已知的牌，用有限的公开出牌情境估计其效果和场面贡献；升级牌只枚举有界数量的公开宿主。
3. 保留已有的场面结构与印刷琥珀基础值作为 fallback。效果未完全建模、当前费用不足或没有可确认窗口时，不把一张牌的以后留存价值直接抹成零。
4. 普通质量估计关闭生命周期递归和终局紧急加分，随后再单独处理区域与时机。有限候选数、效果深度及调用层次共同限制计算量。

出牌情境只使用原观察者已经可见的牌。重新从对方所有者角度估计一张公开牌时，不继承双方的隐藏手牌或暗置档案身份，也不把对方未来的回合历史伪造为完整信息。公开顶牌或明置档案被移动到估计手牌时，会同步移除其原位置与对应计数，避免同一物理牌同时存在于两个区域。

这能够利用当前场面、资源、公开效果结构和当前窗口中的一部分组合关系。例如，一张回收来的行动牌是否能立即正常打出，其效果能否利用当前资源，以及某个公开限制是否会阻止它。它尚未构成完整牌组的组合搜索：不会为每张弃牌重复分配同一个未来回收能力，也没有完整模拟多张牌的未来出牌顺序、同牌替代关系或所有循环引擎。

## 4. 再使用时机与一次补牌差分

### 4.1 当前可用窗口与以后留存价值分开

当前出牌机会要结合行动方、当前屋、阶段、Omega、当前次数限制、可见禁用效果、印刷资源要求和实际支付成本判断。真实合法动作仍是当前可执行性的直接依据；针对回收和归档选择推断的窗口保持有界。

因此，回收到手的牌可以具有以后留存价值，同时没有本回合正常打出的机会。归档一张当前仍能使用的牌，也会失去即时节奏。回合结束阶段已经经过正常补牌后的归档，不再次领取本回合补牌位，也不自动获得当前出牌窗口。

### 4.2 延迟折价仍是启发式

手牌、档案、弃牌堆和牌库之间的时间折价使用公开区域、公开牌库数量和正常补牌目标估计。当前已有合法原生自回收动作的牌，可以获得更短的访问等待；未来共享回收来源不逐张重复分配。

已知牌库顶可以估计是否进入下一次正常补牌；已知牌库底用公开牌库遍历时间估计。实际执行洗回牌库时，下一次正常补牌抽到该牌的部分机会使用抽取张数与洗后牌库数量的比例，其余访问机会继续折价。

这些仍是有限时域的策略近似。没有发生洗牌、或没有公开位置时，不借“抽取概率”之名假定牌库均匀排列。当前公开手牌阻塞、链和补牌修正也可能让简单时间折价失准；无法确定的部分保留近似或未知标记。

### 4.3 补牌只在整次候选动作结算一次

补牌收益以完整候选动作的手牌与可抽供给变化为单位计算，不在每个被移动目标上分别奖励一次。这样可处理多张归档、绑定选择、连续回收，以及同一候选中相互抵消的移动。

例如，在正常补牌目标为 6、供给足够且没有其他修正时，手牌从 7 张变为 5 张，只多得到 1 个正常补牌位。逐张计算两张离手牌会错误地奖励 2 个位置。当前沿用已有循环策略每个正常补牌位 0.9 的效用单位；这个数字是评分单位，不是琥珀数量或胜率增量。

如果候选同时改变链、补牌规则依赖尚未确定的动态效果，或区域计数已变得不确定，则不领取未经证实的精确补牌差分。单次固定归档有利与否，仍须与该牌失去的使用机会一起比较。

## 5. 目的地、替代效果与绑定续段

### 5.1 外来档案按实际返回处理

公开的 `foreignArchiveHolder` 标记与实际档案位置共同决定离开档案的替代。适用时，尝试清除、洗回或移走的牌实际回到所有者手牌；估值、区域计数和后续公开数量使用这个实际目的地。

“尝试清除”被替代为“回到所有者手牌”时，清除本身没有成功。依赖 `after(affected)` 的支付或奖励不会把这个结果当作成功清除。可见的外来档案锁先阻止离开；标记随实际离档处理，不能因为原来的归档来源离场就擅自失效。

缺少足以确认替代或锁的信息，或 `archiveTo` 依赖当前未提供的事件所有者绑定时，评分器保留具体未知原因。它不读取裁判内部对象补齐信息，也不把缺失持有者默认当成己方档案。

### 5.2 组合绑定按物理身份去重

已支持的选择、绑定和合并绑定续段可以把多个公开集合合并后操作。合并按物理牌身份去重，避免同一张牌在重叠集合中被归档两次或重复计值。

移动前的绑定与移动后新选择区分处理。一次已知区域移动并不意味着此前绑定可以无条件指向新的入区实例。未知多部件目的地、未知替代或其他未建模续段，不会被登记为确定成功的移动，再拿去支付后续奖励。

## 6. Scrap 与原动作的来源帧

Scrap 的收益取决于实际事件。模型只在当前行动玩家的牌确实从其手牌弃到弃牌堆、且公开文本提供 Scrap 时计算已支持的 Scrap 效果。归档、从牌库弃置、场上离开，或非当前玩家的手牌被迫弃置，不因此自动获得同一份 Scrap 收益。Destroyed 仍按已有破坏评估和真实破坏回执处理。

同一批直接移动先完成，再评估这些移动触发的 Scrap 子效果。因此，Scrap 读取弃牌堆数量时可以看到本批已经实际弃掉的其他牌。

本轮还修复了子效果的来源帧问题。评估 Scrap 时：

- 来源切换为实际被弃置的物理牌，`sourceOnly` 在其实际区域中解释。
- 继承父动作已经发生的公开投影。父 Play 的牌已经离手、父生物已经入场、出牌次数与对应屋的计数不会被重置。
- 已弃置的 Scrap 生物不会因为外层动作是 Play，再次被加入虚拟场面。
- Scrap 子效果结束后恢复父来源，随后父效果继续使用原本的来源身份。

受控公开输入已核对手牌身份与手牌数量一致、父 Play 计数保留、Scrap 来源位于弃牌堆，以及子效果结束后父来源恢复。复杂反应、未建模的离场续段和其他不确定事件继续保留未知状态，不据此保证后续铸钥匙。

## 7. 严格的回收后第三钥匙机会

普通使用机会与终局紧急优先级分开。严格回收判断只处理公开信息足以确认的窄路径：单一明确回收提示、可确认的来源能力与动作窗口、没有可见未完成父效果或调用歧义、回收牌可以正常打出，并且实际资源和当前钥匙费用足够。

本轮把适用来源从原先只认单一 Play 回收扩展到可明确识别的单一 Reap 回收，因此覆盖 Witch 的受控反例。实现按结构化能力和公开动作窗口判断，不按 Witch 或 Key Charge 的牌名特判。

反例门控覆盖当前屋不匹配、noActions、noPlay、铸钥匙封锁、Gold Key Imp 类公开禁令、钥匙税、当前出牌容量、同名六次规则、未知公开状态，以及 Gravid Cycle 的 Omega 结束窗口。对于可见复制、授予能力、条件文本、多目标、after 续段或未完成父效果，严格路径保守退出。

例如，在“当前 7 琥珀、打出后先失去 1、钥匙费为 7”的税费对照中，回收到手并没有创造足够资源。强优先级不能使用费用变化前的数值证明获胜。

这个分量表达“后续正常动作存在已证实的机会”。回收评分不会把钥匙数直接加一，也不会将 returnHand 写成已经 Play 或已经 Forge。不能达到严格证明条件的牌，仍可以获得普通生命周期估值。

## 8. 证据层次与强度验证设计

本轮分别保留四类证据：

| 证据 | 可以支持的结论 | 不能替代的结论 |
| --- | --- | --- |
| 32 局冻结基线诊断 | 真实公开提示、候选分数和实际选择中的覆盖缺口 | 候选强度、错误率、最优策略证明 |
| 冻结裁判的受控合法路径 | 指定局面中的规则结果与合法下一步 | 该局面在自然对局中的频率 |
| 当前候选的公开输入重放与专项回归 | 区域、窗口、成本、替代和来源帧的具体行为 | 未覆盖卡牌或任意组合的正确性 |
| 预先固定的新种子对照 | 固定牌组集合和实验协议下的候选表现 | 线上胜率、未见牌组泛化、单项修复的因果收益 |

强度对照在候选对局开始前固定为 96 局开发批次与 384 局确认批次，两批均已完整完成，基线为冻结 0.6.1。确认使用事先预留的新对局种子，保持同一组 12 副公开牌组；候选席位与先后手交叉平衡。两个策略家族分别报告，四局配对单元作为分析单位。已查看的 32 局诊断、公开重放场景，以及之前版本的对局不混入这 480 局。

确认批次不按中途胜率追加、提前停止或反复调参。新种子提供新的洗牌条件；牌组集合本身仍然已知，不能称为未见牌组验证。

下节同时报告自然完赛、异常与技术终止、完整配对单元、置信区间及耗时分布。单个机制修复改善了指定局面的判断，并不足以证明整场胜率变化由它单独造成。

## 9. 完整比较、行为与成本

## 10. 当前边界与实现入口

评分器使用 Observation 中对当前玩家公开的信息，包括其自身可见手牌与档案、双方公开场面和弃牌、公开计数、明确提示与合法动作。它不读取隐藏牌库顺序、对手隐藏手牌、裁判随机状态或内部效果队列。受控测试可以由冻结裁判建立局面和验证合法路径；策略收到的仍是公开 Observation。

当前保留的边界包括：

- 时间折价、普通牌质量与机会差仍是启发式，不能解释为精确胜率。
- 没有完整牌组组合求解，也没有为未来共享回收引擎进行全局资源分配。
- 复杂复制、变形、多部件牌、未知条件或授予文本，以及不确定的离场响应，需要更窄的保守处理。
- 32 局诊断没有建立全部非在场牌库顶、牌库底和洗回目标选择的自然覆盖；专项公开场景补充这些边界，不能把未出现视为已通过。
- 已知直接移动、请求操作是否成功、后续反应是否可确定分别表达。效用分带近似标记不等于直接移动失败；直接移动已知也不等于所有后续反应都已建模。
- 既有历史运行时继续冻结；新行为由生命周期开关进入候选路径。历史比较不使用变动后的候选字节冒充基线。

实现可从以下仓库模块审阅：

| 模块 | 职责 |
| --- | --- |
| `src/ai/card-lifecycle-value.ts` | 公开区域识别、实际目的地、所有者与持有者、机会差与整体补牌差分 |
| `src/ai/public-card-opportunity.ts` | 复用公开效果评估器的有界普通质量与当前窗口估计 |
| `src/ai/public-card-value.ts` | 既有场面操作与生命周期结果组合，保持请求成功回执 |
| `src/ai/algorithm-policies.ts` | 候选动作中的区域投影、组合绑定、整次补牌结算与 Scrap 来源帧 |
| `src/ai/recovery-forge.ts` | 严格的回收后正常出牌第三钥匙机会判断 |

诊断摘要、最终源码与运行时绑定、专项回归及完整对照结果分别纳入公开证据摘要，保留各自分母和适用范围。公开导出采用字段白名单，保留核验所需的聚合统计、区间、性能计数和哈希；不直接发布原始对照记录或命令轨迹中的牌组身份、路径、错误栈以及可能附带的裁判内部状态。


## 11. 仍值得继续改进的估值

本轮结果支持继续围绕具体公开决策分析以下问题，尚不支持直接给这些方向指定统一加分权重。

| 方向 | 当前缺口 | 有价值的下一步 |
| --- | --- | --- |
| 循环／Scrap 与当前出牌机会 | 确认中可打同牌时弃牌次数更多、每回合出牌和收割略少，但尚未逐例判定收益 | 保存这些选择的公开候选与分项，核查是否对循环收益或 Scrap 估得过高，再形成具体正反例 |
| 关键回合的资源阈值 | 普通留存值保留了尚未能支付的关键牌，但没有完整计算未来资源与屋选择的联合机会 | 将“当前可证实的第三钥匙”与较远的资源达标概率继续分开，用公开路径构造正反例 |
| 多张关键牌与共享回收 | 一个未来回收能力无法同时给每张弃牌提供完整收益 | 按同一能力的次数和窗口统一分配，避免逐牌重复承诺回收 |
| 同牌与功能替代 | 多张相同或等价牌的边际价值依赖手牌、档案、剩余循环与对手 | 在具体局面比较保留第一张与额外副本的收益，不能一律按副本数折价 |
| 归档与爆发回合 | 单牌访问折价仍不足以表达跨屋储存和多牌连续出牌 | 用有限公开动作序列检查取档时机、手牌拥堵与本回合收益 |
| 计算成本 | 公开场景 CPU 栈已确认材料估计与组合搜索有界嵌套，比赛慢调用仍缺决策级定位 | 先记录决策级耗时和热点，再验证缓存键完整性与分数不变性 |
| 未覆盖的操作上下文 | 记录器仍不能精确分类部分 select，复杂绑定与原生调用帧也存在未知 | 先补明确语义和可重放证据，再加入数值估计 |

这些方向中，重复计算与共享回收资源都有明确的工程或模型边界；它们仍需独立实现和验证，未计作 0.6.2 已完成能力。

## 多张回收怎样计分

**先看牌最后到哪。** 结算手牌机会时，每张已知移动实体按最初与最终位置计一次净差；普通效果与 Scrap 仍按各自规则逐步结算。旧版受控例子把单牌普通材料值固定为 4，得到进手 +3.2、随后离手 -1.2，往返残留 +2。新版消费者的两条测试分别比较经过手牌再弃掉、经过手牌再清除与直接抵达相同目的地，均消除了这笔临时收益。

**当前可用的机会由整手牌共享。** 在相同的已知费用、资源与剩余限制下，分别估计移动前后手牌中一组可连续打出的牌相对留手的即时溢价，然后取差。可证实的跨势力许可也参与分配；多张牌共享同一个许可、剩余出牌次数或琥珀池。Alpha 的首次行动要求、Omega 关窗、禁用和同名六次限制会约束组合。回收后遇到未解析的续段或公开状态不完整时，模型会保守放弃即时溢价。组合搜索每一步最多保留 48 个候选状态，因此结果仍是估计。

**再看留下的同势力搭档。** 每个势力有第一张留手牌后，每多一张可搭配的留手牌贡献 0.3 分。己方可见且可正常取回的档案至多作为半个搭档，贡献 0.15 分。模型按有效势力计算，场上临时改屋在离场时复原，实体额外势力仍保留。对每个势力比较候选前后，取最大正增量与最大损失相加，整次修正限制于 −1.2 到 +1.2 分。这样一张多势力实体不会在多个势力重复加分，原有大势力也不会遮住另一势力刚形成的搭档。已分配给当轮即时出牌的实体从对应时点的未来搭档中排除。

例如，原手牌没有 Logos，收回两张本回合均须留手的 Logos，未来组合增加 0.3；若其中一张已经获得本轮出牌机会，留下的一张没有其他搭档，就没有这笔 0.3。若本轮允许跨势力打出两张不同势力的牌，二者可各自争取即时价值。这些权重描述可见手牌的合作机会与行动时机，牌间具体文本联动仍取决于公开效果估值。

### 一个仍然选择弃牌的开发局面

从既有开发集中选取编号最小、候选方曾在同牌可打时弃掉无 Scrap 牌的对局。按原输入重建这一个开发局后，256 条指令的数量和序列指纹、胜者及终态指纹均吻合；其中有 1 次符合条件的决策。重建没有增加胜率样本。

Engine V3 在第 3 回合弃掉 **Generous Offer**。它没有印刷琥珀或公开 Scrap 文本，打出后需实际摧毁一只友方生物，才能偷取至多 2 琥珀。当时己方有 2 只生物，对方有 0 琥珀，可偷取量为零。打出、弃牌和结束回合的评分分别为 **-2.120、0.357、0.000**，打出和弃牌都只得到一次腾位补牌收益。这个局面解释了策略为何避开要付出己方生物的空收益出牌；它没有给出保留这张牌到后续回合的实战结果，也无法代表其他弃牌的质量。

## 目前仍有限的估值

本轮修正了补手位比较的不对称和同一机会被重复分配的问题，但以下部分仍采用近似：

- **留到下一次同势力回合的价值。** Generous Offer 例子只说明当下打出不划算；对手以后可能攒出琥珀，是否值得占住手牌等待，还需要把等待时间、换牌收益与未来局面一起估计。
- **先做一张牌，再开放下一张牌的行动链。** 当前窗口共享已知资源和额度，但不完整搜索先赚琥珀、改变出牌许可或改变场面后再继续打出的顺序。被模型识别为会占用共享目标、消耗资源或限制后续出牌的牌，保守地放在最后一个被估价的位置，未解析的续段可能使即时奖励被放弃。
- **同势力搭档的具体质量。** 每搭档 0.3、总修正不超过 1.2 是有界启发式，并未证明是最优参数。它表达共同调用势力的机会；两张具体牌的连动、局势紧迫度与下一回合能否轮到这个势力，仍可能使真正价值不同。
- **直接多选操作的覆盖。** 本轮补齐已选前缀的直接操作是回手与归档；不能据此推断所有多目标操作都具备完整的组合规划。

这些边界适合后续按实际决策单独验证。本次把多个估值修正一起比较，未隔离每项改动对胜负的贡献。
